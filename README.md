# Joshua Ojabo — Portfolio

Standalone portfolio website

## Files
- `index.html`
- `styles.css`
- `script.js`

## Run locally
Open `index.html` directly, or use a static server.

## Deployment
Compatible with Vercel, Netlify, GitHub Pages, Cloudflare Pages and standard static hosting.

!!! AI tools were used to support the visual styling and refinement of this portfolio, including suggestions for layout, spacing, responsiveness, and CSS improvements. The portfolio content, project decisions, implementation, testing, and final review were completed and verified by me.

No framework, backend, external UI library, or Base44 runtime is required.
